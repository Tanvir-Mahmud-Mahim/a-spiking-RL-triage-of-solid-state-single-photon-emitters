# SPARQ — Spiking Physics-in-the-Loop Autonomous Reinforcement Triage of Quantum Emitters

Complete codebase for the manuscript:

> **SPARQ — spiking physics-in-the-loop autonomous reinforcement triage of
> quantum emitters: a closed-loop, event-driven machine-learning framework
> for characterizing solid-state single-photon sources**
> Tanvir M. Mahim, Md Nahin Islam, M. Mosaddequr Rahman, Abu S. M. Mohsin
> *(under review, APL Machine Learning)*

Every figure and every number in the manuscript is generated by the code in
this repository — no hand-typed results anywhere.

## What SPARQ does

Certifying a solid-state single-photon emitter with a Hanbury Brown–Twiss
(HBT) measurement of g²(τ) takes minutes per candidate site; screening a
sample takes hours. SPARQ attacks the whole pipeline in one closed loop:

- **Validated digital twin** of the HBT measurement at two fidelities
  (analytic Poisson histogram twin + full Monte-Carlo photon-stream
  simulator with IRF jitter, dead time, afterpulsing, blinking,
  multi-emitter dilution), validated against numerically exact
  master-equation statistics (χ²ν = 0.86–1.21) and real pulsed
  quantum-dot data.
- **Physics-in-the-loop estimators**: a CNN and a surrogate-gradient
  spiking neural network trained *through* the twin reach the 90%
  triage-accuracy target 6–7× faster than a strong multi-start
  least-squares fit, benchmarked against a Monte-Carlo Bayes
  information limit.
- **Anytime, nanojoule inference**: the SNN produces gateable decisions
  with 312 ms median latency at event-proportional energy
  (768 nJ – 4.2 µJ per decision in Loihi synop accounting).
- **Adjoint protocol optimization**: pathwise gradients through the
  differentiable twin redesign the measurement protocol itself and land
  on the profile-Fisher-information optimum (+2.7 accuracy points in the
  photon-sparse regime).
- **Sim-to-real audit** on the open *sps-quality* quantum-dot dataset:
  2.0× lower early-estimation error than peak-area analysis, zero-shot,
  with a WGAN-GP critic showing the twin already sits within 24% of the
  information floor.
- **Closed-loop RL triage**: discrete Soft Actor-Critic + prioritized
  experience replay screens simulated emitter fields 1.7× faster than
  raster scanning (clairvoyant oracle bound: 8.8×).
- **Zero-shot cross-platform transfer**: graph-encoded level structures
  (NV, hBN, GaN, SiV) recover 92% of the specialist accuracy gap on
  platforms never seen in training.

## Repository layout

```
sparq/                    core library
  physics.py              emitter photophysics, platform priors, histogram
                          twin and Monte-Carlo photon-stream simulator
  exact.py                numerically exact master-equation g2(tau)
  pulsed.py               pulsed-excitation twin, comb calibration,
                          peak-area analysis
  datasets.py             synthetic acquisition generators + loader for
                          the real sps-quality quantum-dot HBT data
  estimators.py           multi-start LM-fit baseline, CNN, spiking
                          network, physics-in-the-loop training
  twin_torch.py           differentiable twin (adjoint/pathwise gradients)
                          + profile Fisher information
  sac_per.py              discrete Soft Actor-Critic + prioritized
                          experience replay (sum-tree)
  rl_env.py               closed-loop triage environment + baselines
  gnn.py                  level-structure template graphs + message-passing
                          encoder for cross-platform transfer
experiments/              one script per experiment (exp1..exp6b) +
                          make_numbers.py / make_supp.py, which regenerate
                          every macro and table in the manuscript
figures/                  figure scripts (fig0..fig6) + house style
results/                  JSON outputs of all experiments (the benchmark
                          numbers used by the manuscript)
run_all.sh                run the full experiment suite in order
```

## Installation

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Python ≥ 3.10. The experiments run on CPU; a GPU is optional.

## Reproducing the paper

```bash
bash run_all.sh                 # full suite (twin validation -> transfer)
# or individually, e.g.:
python experiments/exp1_validate_twin.py
python experiments/exp2_estimators.py
python experiments/make_numbers.py   # regenerates all manuscript macros
python figures/fig2_validation.py    # regenerates a figure
```

Each experiment writes a self-describing JSON to `results/`; the figure
scripts and `make_numbers.py` consume those JSONs, so the manuscript's
numbers update automatically when an experiment is re-run.

## Data

- **Benchmark data + trained model checkpoints**: deposited on Zenodo
  (DOI in the manuscript's Data Availability section).
- **Real quantum-dot HBT measurements**: not redistributed here; openly
  available from the UTS-CASLab
  [sps-quality](https://github.com/UTS-CASLab/sps-quality) repository
  (Kedziora *et al.*, Mach. Learn.: Sci. Technol. **4**, 045042 (2023)).
  Point `sparq/datasets.py` at your local copy to run the sim-to-real
  experiments (exp4).
